# 符箓副武器系统设计

## 概述

新增黄色道具类型「符箓」，作为副武器系统。场景中以黄色发光道具出现，拾取后自动装备，自动攻击或自动触发效果，有次数制耐久，用完消失。最多同时携带2个。

## 核心规则

| 规则 | 值 |
|------|-----|
| 道具颜色 | 黄色（0xffaa00）发光 |
| 最大携带数 | 2个 |
| 耐久类型 | 次数制（每次攻击/触发消耗1次） |
| 满槽时拾取 | 替换最早获得的那个 |
| 自动行为 | 不需要玩家操作，按攻击间隔自动触发 |

## 3种符箓

### 追魂符

| 属性 | 值 |
|------|-----|
| 耐久 | 20次 |
| 伤害 | 12/次 |
| 攻击间隔 | 1.0秒 |
| 攻击范围 | 60 |
| 投射物速度 | 50 |
| 追踪能力 | 轻度追踪（lerp 2/秒） |

**行为**：每1秒自动锁定距离玩家最近的存活敌人，发射一枚黄色追踪灵弹。灵弹有轻微追踪能力，命中或超出范围后消失。

**视觉**：
- 待机：玩家左肩侧悬浮一张黄色符纸，缓慢旋转
- 攻击：符纸闪光，发射黄色小球（SphereGeometry r=0.2）
- 投射物有黄色拖尾

### 雷罚符

| 属性 | 值 |
|------|-----|
| 耐久 | 10次 |
| 伤害 | 30/次（AOE） |
| 攻击间隔 | 2.5秒 |
| 攻击范围 | 40（锁定范围） |
| AOE半径 | 8 |

**行为**：每2.5秒对范围内最近的敌人释放一道雷电。以目标位置为中心，AOE半径8内所有敌人受伤。高伤害低频率，适合面对密集敌群。

**视觉**：
- 待机：玩家右肩侧悬浮一张紫黄色符纸
- 攻击：从符纸上方降下一道白黄色闪电柱（CylinderGeometry，从y=150到目标位置），持续0.2秒后消失
- 命中点产生扩散光环

### 金刚符

| 属性 | 值 |
|------|-----|
| 耐久 | 15次 |
| 回复量 | 8 HP/次 |
| 触发间隔 | 3.0秒 |
| 总回复量 | 120 HP |

**行为**：不攻击敌人。每3秒自动回复8HP，消耗1次耐久。15次用完消失。玩家满血时仍然触发（不浪费耐久，方便设计）。

**视觉**：
- 待机：玩家头顶悬浮一张绿金色符纸
- 触发：玩家周身闪烁绿色光环，持续0.3秒淡出

## 场景生成

在现有 Pickup spawn 逻辑基础上扩展：
- 现有 `pickupSpots` 中随机选取2-3个位置生成符箓道具
- 符箓类型随机从3种中选取
- 每关（`initLevel`）重新生成

## 获取方式

符箓不在固定位置刷新，通过以下两种途径获取：

### 1. 场景宝箱

- 每关生成2-3个宝箱，放置在 `arena.pickupSpots` 的位置上
- 宝箱外观：金色方块（BoxGeometry 1.0），上下浮动+旋转，发光
- 玩家飞近宝箱（碰撞半径2.0）自动开启
- 打开后随机掉出1个符箓（3种等概率），宝箱消失
- 打开时播放 `chestOpen` 音效

### 2. 击杀敌人掉落

- 每个敌人死亡时有概率掉落1个符箓
- 掉落概率：灵鸦 15%、岩蟒 30%、蛟龙 50%、Boss 100%
- 掉落的符箓在敌人死亡位置生成，悬浮等待拾取
- 掉落物10秒后自动消失（避免场景堆积）
- 掉落类型随机（3种等概率）

### 道具外观

- 宝箱：金色方块（1.0大小），emissive 0xdaa520
- 掉落符箓：黄色小方块（0.7大小），emissive 0xffaa00，上下浮动+旋转

## 拾取提示

拾取时屏幕居中显示大字提示，1.5秒后淡出：

```
「获得 追魂符」
自动追踪攻击最近敌人
```

样式：
- 第一行：金色（#ffd700），字号28px，加粗，带书名号「」
- 第二行：浅灰色（#ccc），字号14px，功能描述
- 背景：无（纯文字+阴影）
- 出现动画：从 opacity:0 + scale(0.8) 到 opacity:1 + scale(1)，0.2秒
- 消失动画：opacity 淡出 0.3秒

## HUD显示

在底部状态栏中，HP条右侧添加符箓槽位：

- 2个方形槽位（28×28px），金色边框
- 空槽位：暗灰色边框，无内容
- 已装备：显示符箓颜色色块 + 右下角耐久数字
  - 追魂符：黄色色块
  - 雷罚符：紫黄色色块
  - 金刚符：绿金色色块
- 耐久为0时槽位清空

## 与现有系统的关系

| 现有系统 | 变更 |
|----------|------|
| `src/world/Pickup.ts` | 扩展为支持宝箱（chest）和符箓掉落（talisman_drop）类型 |
| `src/config.ts` | 添加 `talismans` 配置段（3种符箓数值 + 掉落概率） |
| `src/Game.ts` | spawnPickups 添加宝箱生成；敌人死亡时按概率掉落符箓；update 中调用 TalismanSystem.update；掉落物10秒超时清理 |
| `src/enemy/Enemy.ts` | 不修改，掉落逻辑在 Game.ts 的 onEnemyKilled 中处理 |
| `src/ui/Hud.ts` | 添加符箓槽位显示、拾取大字提示方法 |
| **新建** `src/player/TalismanSystem.ts` | 符箓管理：携带、自动攻击/回复、耐久消耗、视觉效果 |
| `src/shared/Sfx.ts` | 添加符箓相关音效 |

## 数值平衡

- 追魂符 DPS：12/秒，20秒持续 → 总伤害240。对比灵刃散射 DPS 约30（15×3/1.5秒），追魂符约占主输出的40%，作为补充输出合理
- 雷罚符 DPS：12/秒（30/2.5），但AOE能打多个，密集敌群时价值翻倍
- 金刚符总回复120HP > 玩家满血100，能完整回一次血+多一些余量
- 一关4波，场景2-3个宝箱 + 击杀掉落，预计每关可获得3-5个符箓
- 掉落概率偏低（灵鸦15%），避免符箓过剩，保持稀缺感
