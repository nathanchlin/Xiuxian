# 主角4技能BD设计 — 剑法双修·资源循环流

## 概述

设计4个主角技能，形成「远程积累→近战收割→防御反击→终结爆发」的战斗循环。核心机制是双资源系统（灵力+剑意叠层），远程技能积累剑意，满层后释放穿透终结技。

## 资源系统

### 灵力（已有，调整用途）

| 属性 | 值 |
|------|-----|
| 上限 | 100 |
| 自然回复 | 5/秒 |
| 用途 | 技能1/2/3消耗，终结技额外消耗 |

### 剑意（新增叠层资源）

| 属性 | 值 |
|------|-----|
| 上限 | 5层 |
| 自然回复 | 无 |
| 获取方式 | 技能命中敌人 |
| 衰减 | 10秒不命中敌人，衰减1层 |
| 用途 | 满5层解锁终结技 |

HUD显示：剑意用5个剑形图标表示层数，点亮为已获取。满层时图标发金光脉冲提示。

## 技能设计

### 技能1：灵刃散射 (Q)

| 属性 | 值 |
|------|-----|
| 类型 | 远程、扇形AOE |
| 灵力消耗 | 8 |
| 冷却 | 1.5秒 |
| 射程 | 80 |
| 伤害 | 15/道，共3道 |
| 扇形角度 | 15° |
| 剑意获取 | 每道命中+1（最多+3） |

**视觉**：前方扇形发射3道青色弧形光刃，飞行速度60/秒，命中时目标闪白。

**定位**：主要远程输出和剑意积累来源。低消耗高频率，保持战斗节奏。

**实现要点**：
- 3道投射物，从玩家前方以-7.5°、0°、+7.5°偏移角发射
- 每道是独立的投射物，有碰撞体积（半径1）
- 命中后销毁该道灵刃
- 使用BufferGeometry绘制扁平光刃形状

### 技能2：御剑突刺 (F)

| 属性 | 值 |
|------|-----|
| 类型 | 近战、突进 |
| 灵力消耗 | 20 |
| 冷却 | 3秒 |
| 突进距离 | 20 |
| 突进时长 | 0.2秒 |
| 伤害 | 60 |
| 无敌时长 | 0.3秒 |
| 剑意获取 | 每命中一个敌人+2 |

**视觉**：角色化为剑光高速前冲，留下青色剑痕拖尾，命中敌人时产生十字斩击特效。

**定位**：近战收割+穿场位移+危险回避。高灵力消耗换取高伤害和无敌帧。

**实现要点**：
- 复用FlightController的dash机制，升级为技能
- 突进方向为玩家当前朝向
- 突进期间设置`dashInvincible = true`
- 碰撞检测：突进路径上的球形扫描（sweeptest），对路径上所有敌人造成伤害
- 每个敌人只被命中一次（用Set记录已命中ID）

### 技能3：剑气护体 (R)

| 属性 | 值 |
|------|-----|
| 类型 | 防御、反击 |
| 灵力消耗 | 15 |
| 冷却 | 5秒 |
| 格挡窗口 | 0.8秒 |
| 反弹伤害 | 50 |
| 剑意获取 | 格挡成功+3 |

**视觉**：
- 激活时：身前出现旋转的剑阵护盾（6把小剑环绕形成圆环）
- 格挡成功：剑阵爆炸扩散，反弹伤害给攻击者，金色闪光
- 格挡失败（超时）：剑阵淡出消散

**定位**：高风险高回报的主动防御。奖励对敌人攻击时机的判断。

**实现要点**：
- 激活后设置`parrying = true`状态，持续0.8秒
- 在Game.ts的`applyDamageToPlayer`中检查parry状态
- parry成功：取消伤害，对攻击源施加反弹伤害，+3剑意
- parry期间不叠加（重复按R无效）
- 需要追踪"谁攻击了玩家"信息以反弹伤害

### 技能4：万剑归宗（终结技，满层自动解锁）

| 属性 | 值 |
|------|-----|
| 类型 | 终结、穿透射线 |
| 消耗 | 5层剑意（全部清空）+ 30灵力 |
| 冷却 | 无（受剑意限制） |
| 射程 | 200 |
| 伤害 | 150/目标 |
| 蓄力时间 | 0.5秒（可转向瞄准） |

**视觉**：
- 蓄力阶段：角色举剑，身周聚集金色剑气粒子，屏幕轻微缩放（FOV从78→72）
- 释放：一道巨大金色剑光从玩家前方射出，直径约3，穿透所有目标
- 命中：每个目标产生金色爆炸环特效
- 射线持续0.3秒可见后淡出

**定位**：蓄力后的爽快终结。奖励玩家持续战斗积累剑意的努力。

**实现要点**：
- 触发条件：剑意=5时，按左键释放
- 蓄力0.5秒期间玩家可旋转瞄准但无法移动
- 射线使用raycaster检测路径上所有敌人（非只第一个）
- 视觉上用CylinderGeometry做粗光柱
- 释放后清空剑意，播放屏幕震动效果

## 按键映射

| 按键 | 技能 | 说明 |
|------|------|------|
| Q | 灵刃散射 | 新增按键 |
| F | 御剑突刺 | 升级原飞剑冲刺 |
| R | 剑气护体 | 新增按键 |
| 左键 | 万剑归宗 / 普通灵弹 | 满5层剑意时为终结技，否则为原灵力射线 |

原Tab（现Shift）的加速保持不变。

## 战斗循环

```
[远程阶段] Q灵刃散射 ×2-3 → 积累3-9剑意（上限5）
    ↓
[突进收割] F御剑突刺 → 穿过敌群+2剑意/敌
    ↓
[被攻击时] R剑气护体 → 格挡反击+3剑意
    ↓
[剑意满层] 左键 万剑归宗 → 贯穿一切 → 清空剑意
    ↓
[循环重启] 回到远程阶段
```

典型对战节奏（约8-12秒一个循环）：
1. Q散射×2（积累2-4层剑意）→ 3秒
2. F突刺穿过（补满到5层）→ 0.2秒
3. 左键终结技（清空剑意）→ 1秒
4. 灵力回复间歇 → 2秒

## HUD变更

在现有HUD基础上添加：

1. **剑意指示器**：屏幕中下方，HP条上方，5个剑形图标横排
   - 未激活：暗灰色轮廓
   - 已激活：青色发光
   - 满层：全部变金色+脉冲动画
2. **技能冷却指示器**：屏幕左下方武器信息旁，显示Q/F/R冷却状态
3. **终结技提示**：满层时屏幕中央出现"按左键 — 万剑归宗"文字提示

## 与现有系统的关系

| 现有系统 | 变更 |
|----------|------|
| WeaponSystem | 重构为SkillSystem，管理4个技能的冷却/消耗/效果 |
| FlightController.spirit | 保持不变，作为技能消耗资源 |
| FlightController.dashing | 被技能2接管，不再独立 |
| 原灵力射线（左键） | 改为：未满层时发射普通灵弹（保留），满层时触发终结技 |
| 原符箓追踪弹 | 移除，被灵刃散射取代 |
| config.ts weapons | 替换为 skills 配置段 |

## 数值平衡依据

- 灵力回复5/秒，Q消耗8 → 每1.6秒可释放一次Q
- Q×3 + F×1 最多积累 9+2 = 11剑意 → 上限5层，不会浪费太多
- 终结技150伤害 vs 灵鸦30HP → 一击必杀小怪，Boss需多轮循环
- 格挡窗口0.8秒 → 比较宽松，面向休闲玩家友好
