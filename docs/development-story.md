## 一、项目概述

「仙侠空战」是一款 3D 空战游戏，玩家御剑飞行，在浮空仙岛间斩妖除魔。整个项目从零开始，通过与 Claude Code（AI 编程助手）的对话协作完成，全程无手写代码。

**技术栈**: TypeScript + Three.js + Vite，纯程序化生成（无模型/贴图/音频文件），Web Audio 合成音效。

## 四、开发模式总结

### 1. 对话即编程

整个项目没有写过一行代码。所有功能都通过自然语言对话实现：
- **需求表达**：用中文描述想要什么（"技能1发射12把自动追踪飞剑"）
- **问题反馈**：描述体验问题（"怪物贴脸打不中"）
- **数值调优**：说感受不说数字（"Boss血太厚"）

### 2. 设计先行

复杂功能遵循 设计文档 → 实现计划 → 编码 的流程：
- 4技能系统：先写完设计文档确认机制后才编码
- 符箓系统：先确认获取方式和战斗机制
- 背包系统：先通过选择题确认复杂度方向

### 3. 体验驱动迭代

不是按照需求列表线性开发，而是不断试玩 → 反馈 → 修复的循环：
- 每次修改后自动构建部署，立即可玩测试
- "Boss血太厚" → 800→400→250，三轮调优到位
- 背包快捷键 Tab→B，鼠标释放，都是试玩后发现的问题

### 4. 全栈一体

AI 同时处理：
- 游戏逻辑（技能、战斗、AI）
- 3D 渲染（Three.js 几何体、粒子、光照）
- 音频合成（Web Audio 振荡器）
- UI 系统（DOM HUD、全屏面板）
- 触控适配（虚拟摇杆、手势识别）
- 构建部署（Vite + GitHub Pages）
- Bug 修复（内存泄漏、状态管理）

### 5. 一键部署

每次修改后 `git commit + git push + gh-pages` 一条龙，改完即上线。后期还加了 GitHub Actions 自动部署。
